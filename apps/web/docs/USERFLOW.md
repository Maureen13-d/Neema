# Neema user flow (mother / CHP phone)

```
Splash → Orientation (4) → Consent → PIN set/unlock
    → Home Guardian
         ├─ Live vitals
         ├─ Enter BP
         ├─ Symptoms
         ├─ (on RED/YELLOW) Alert action
         ├─ Mama Passport
         ├─ Nurse summary / QR
         ├─ Contacts
         └─ Settings
Loading overlay / Error recovery anywhere
```

## Screens & primary buttons

| Screen | Purpose | Primary buttons |
|---|---|---|
| Splash | Brand | Anza / Start |
| Orientation | Teach loop | Next, Skip |
| Consent | Sharing choices | Agree & continue |
| Unlock / Set PIN | Local auth | Unlock, Set PIN |
| Home | One status + action | Check band, Add BP, Symptoms, I'm fine |
| Vitals | Live HR/temp | Connect band/simulator, Back |
| Blood pressure | Manual cuff entry | Save reading |
| Symptoms | Tap codes | Save symptoms |
| Alert | Spoken action + SMS | Open SMS, Acknowledge |
| Passport | Profile | Save, Lock |
| Summary | Nurse handoff | Show QR payload, Share choices |
| Contacts | Escalation list | Add / Save |
| Settings | Language, discreet, readiness | Lock session |
| Loading | Wait state | — |
| Error | Recover | Try again, Go home |
